服务器地址

仅 Java 版 · EasyTier 虚拟局域网
Java版EasyTier10.100.100.100

该地址是 EasyTier 组网的虚拟局域网 IP，必须先运行 EasyTier 才能连接；基岩版暂不支持。

入服步骤

  1. 在群文件的「落幕曲」文件夹中下载整合包与 EasyTier 配置。
  2. 安装 easytier-gui.exe，导入 windows.toml，点击「运行网络」。
  3. 启动 PCL CE.exe，登录账号后把落幕曲.zip 拖进去安装整合包。
  4. 启动游戏，进入「多人探险」，添加服务器地址 10.100.100.100。
  5. 详细图文流程见入服方式。
