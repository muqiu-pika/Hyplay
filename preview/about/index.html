关于服务器

Hyplay 服务器是一台 Minecraft Java 版服务器，玩家通过 EasyTier 虚拟局域网直接连接， 使用「落幕曲」整合包开玩，无需端口映射与公网 IP。

  • 客户端：仅 Java 版，基岩版暂不支持
  • 连接方式：EasyTier 虚拟局域网
  • 服务器地址：10.100.100.100
  • 整合包：群文件「落幕曲」文件夹

关于本站

本站是 Hyplay 服务器的官方网站，提供服务器介绍、入服教程与相关链接， 页面不发起任何与连接状态相关的请求。

本版本使用 Vue 3 + VuePress 2 + VuePlume 主题 构建。
